Autofill Playground

Local test pages for the browser's autofill: logins, sign-up, identity/address, <select> menus, and framework / unorthodox markup. Every page has an event panel on the right that logs focusin, keydown, beforeinput (with inputType), input, change and submit, plus a live values table that turns red when a value changed without any input/change event.

Same server, two hosts: localhost vs 127.0.0.1 are different hosts to the browser (see cross-host). Form POSTs land on an echo page; /api/login answers JSON after ~300 ms (password wrong → 401).
